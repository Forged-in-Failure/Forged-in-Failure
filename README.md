# Forged in Failure

Forged in Failure is an indie RPG set in the Skylite Isles. The Skylite Isles are a fog-covered floating archipelago with no formal government. Society's outcasts live there. The project started on Roblox and Luau. The team then moved the full project to Godot and GDScript. The team made this move because of Roblox's weak moderation, platform neglect, and habit of putting features behind a paywall after the features were free.

![Watchtower concept render](./watchtower.png)

## About

The Skylite Isles float across the sky. Fog wraps each isle and eats memories. Each isle has a boss. Until the player defeats the boss on an isle, the fog stays around that isle. The fog slowly strips away the will, goals, and hope of anyone who stays too long. All magic in this world comes from the soul. The player character is a hollow shell that carries two souls at once. This is one reason death is not always the end.

Progression has an open order. The player can fight the strong beings on the isles in any order. Some bosses grow stronger depending on which other bosses have already fallen.

## Core Systems

- **Soul and willpower-based magic**: Armor, accessories, and skills amplify the soul power the player already has. They do not generate new power.
- **Dual-soul protagonist**: This enables respawn mechanics tied to death and revival. A full revival is rare and costly. It can cost the player limbs, abilities, or a stable soul.
- **Fog mechanic**: The fog erodes willpower over time. It also gates the boss fight on each isle.
- **Open-order boss progression**: There is no fixed sequence. Some bosses react to which fights have already happened.

## Classes

The game has four class trees. Each tree has three subclasses.

- **Archer**: A fast ranged DPS class that uses bows and crossbows. Subclasses: Hunter, Arcane Archer, Gunsmith.
- **Mage**
- **Warrior**
- **Rogue**

## Notable Bosses and Creatures

- **Nimbus**: A massive, Robloxian-shaped cloud entity. The fight has three phases: wind, then rain, then lightning-enraged.
- **Grinbloom**: A cheerful-looking bloom that fights with strangling vines, barbed tendrils, and hallucinogenic spores. Its weak point is its face.

## Development

The team uses rotating tasks instead of siloed roles. Contributors move across modeling, art, scripting, writing, and sound as needed. The GDScript migration is complete. The project is now in active implementation.

**Compensation**: Revenue share after launch. The project has no current funding.
