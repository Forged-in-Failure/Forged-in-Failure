# Forged in Failure

An indie RPG set in the Skylite Isles, a fog-covered floating archipelago with no formal governance, home to society's outcasts. It started life on Roblox/Luau but has now fully moved to Godot (GDScript), mainly because of Roblox's weak moderation, platform neglect, and habit of paywalling features that used to be free.

![Watchtower concept render](./watchtower.png)

## About

The Skylite Isles are scattered across the sky, wrapped in a fog that eats memories. Until the boss tied to a given island is defeated, that fog keeps surrounding it, slowly stripping away the will, goals, and hope of anyone who lingers too long. All magic in this world comes from the soul, and the player character is a hollow shell carrying two souls at once, which is part of why death isn't always the end.

Progression is open-order. The strong beings scattered across the isles can be fought in whatever sequence the player wants, and some bosses grow stronger depending on who's already fallen.

## Core Systems

- **Soul/willpower-based magic**: armor, accessories, and skills amplify the soul power you already have rather than generate new power.
- **Dual-soul protagonist**: enables respawn mechanics tied to death and revival, though a full revival is rare and costly (lost limbs or abilities, unstable souls).
- **Fog mechanic**: erodes willpower over time and gates the per-island boss fights.
- **Open-order boss progression**: no fixed sequence, and some bosses react to which fights have already happened.

## Classes

Four class trees, each with three subclasses:

- **Archer**: fast ranged DPS using bows and crossbows. Subclasses: Hunter, Arcane Archer, Gunsmith
- **Mage**
- **Warrior**
- **Rogue**

## Notable Bosses & Creatures

- **Nimbus**: a massive, Robloxian-shaped cloud entity with a three-phase fight (wind, then rain, then lightning-enraged).
- **Grinbloom**: a cheerful-looking bloom that fights with strangling vines, barbed tendrils, and hallucinogenic spores. Its weak point is its face.

## Development

This is a rotating-task team rather than siloed roles. Contributors move across modeling, art, scripting, writing, and sound as needed. The GDScript migration is done, and the project is now in active implementation.

**Compensation:** Revenue share post-launch. No current funding.
